# Como usar o Menuxy

Guia interativo do Menuxy: cada função do sistema com a tela real, passo a passo.
Abra `index.html` ou acesse pelo GitHub Pages.

- **Ver**: os números laranja mostram onde clicar em cada passo.
- **Praticar**: toque na tela onde você clicaria; o guia confere e avança.
- **Trilhas**: primeiro dia, dono, caixa, garçom e cozinha.

O conteúdo (`dados.js`) e as capturas (`telas/`) saem do "Como usar" de dentro do
Menuxy (`includes/guia_conteudo.php` e `assets/guia/`), com uma loja de demonstração.
